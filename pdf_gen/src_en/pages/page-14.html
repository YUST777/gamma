Platform Tech Stack

Frontend and backend
Next.js and TypeScript, with a PostgreSQL database on Supabase, and an installable mobile web app.
Code execution and judging
A Judge0 judge hosted on our own Azure server, supporting C++17, C, Python and Java.
Codeforces integration
Our own proxy service and the Verdict Helper extension auto-sync solved problems and all attempts.
Security and performance
Cloudflare protection, SSL encryption for all data, and error logging to catch issues as they happen.
Open source
The full code is on GitHub under AGPL-3.0; any student can review or contribute.
Ready to scale
Designed to serve other universities; our next goal is to offer it to all Egyptian universities under the Horus name.
