# Bataa pitch deck

## Deliverables

- `output/bataa-pitch-deck.pptx` — editable 16:9 PowerPoint deck
- `output/pdf/bataa-pitch-deck.pdf` — offline-safe PDF backup

## Story

The deck covers the learner problem, Horus University discovery signal, the mobile and desktop product, the beginner learning loop, competitive positioning, revenue model, platform expansion, validation plan, team, and pilot ask.

## Evidence labels

- **Observed** — qualitative themes supplied from Horus University conversations
- **Demonstrated** — product surfaces visible in the current Bataa project
- **Next test** — pilot work or planned business-model expansion

## Before presenting

Replace or confirm the following:

1. Verified number of Horus University participants and consented quotes
2. Exact competitor names and current feature comparison
3. Pilot dates, owners, contact details, and the exact ask
4. Any commercial terms for courses, token packs, marketplace commission, or API access

## Tooling

The editable PPTX was authored with the bundled `@oai/artifact-tool`, validated structurally, rendered slide by slide, and opened through LibreOffice for an independent PDF render check. The open-source `powerpoint-ppt` skill from `practicalswan/agent-skills` was installed for its deck QA checklist. LibreOffice and Poppler were used for the backup render.
